# Isar Flow v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a VS Code extension ("Isar Flow") with an Agents/Workflows sidebar, a river-style block canvas that edits `*.workflow.yaml` two-way, configurable agents on `vscode.lm` + OpenAI-compatible models, and a workflow engine with Agent/Console/Loop/If/Break/Stop/Approval blocks.

**Architecture:** npm-workspaces monorepo. `packages/core` is isomorphic TypeScript (schemas, YAML I/O, expression language, engine, agent runtime, OpenAI-compatible client, protocol types) with no `vscode` import. `packages/extension` hosts providers, runners, custom editors and the run manager. `packages/webview-ui` is a React + Vite app rendered in webviews.

**Tech Stack:** TypeScript 5, Node 20+ (dev on Node 24), `yaml`, `zod`, React 18, Vite, `@dnd-kit/core`, `@vscode/codicons`, `@fontsource/barlow-semi-condensed`, Vitest, Testing Library, esbuild, `@vscode/test-electron`, Playwright (visual harness), `@vscode/vsce`.

**Spec:** `docs/superpowers/specs/2026-10-25-isar-flow-design.md`

## Global Constraints

- Extension display name "Isar Flow", package name `isar-flow`, command prefix `isarFlow.`, settings prefix `isarFlow.`.
- Workspace folder `.isarflow/`; files `*.agent.yaml`, `*.workflow.yaml`; workflow `version: 1`.
- `packages/core` must not import `vscode` or Node built-ins outside `src/node/` (webview bundles core).
- Model refs `<provider>/<model>`, split at first `/`; VS Code models `vscode/<vendor>/<id>`.
- `maxIterations` required on loops, range 1–100, default written by canvas: 5.
- Secrets only in SecretStorage; never written to YAML or logs.
- Webviews: strict CSP (nonce scripts, no remote resources), render model output as text only.
- UI copy in English, sentence case, no all-caps labels inside webviews.
- VS Code engine `^1.95.0`.

## Review Focus

1. Hand-typed YAML with comments → visual edit → comments and unrelated formatting survive (golden tests in Task 5).
2. Windows: PowerShell output encoding (UTF-8), `.cmd` shims (`npm`), and killing process trees on cancel/timeout (Task 11 tests run real processes).
3. Loop termination: `break` in nested `if`, `until` vs `while`, `maxIterations` both modes (Task 7 tests).
4. Expression edge cases: missing step outputs (`undefined`), numeric strings vs numbers in `==`, regex with flags, non-string inputs to string functions (Task 3 tests).
5. Path traversal in agent tools and symlinks out of the workspace (Task 12 tests).
